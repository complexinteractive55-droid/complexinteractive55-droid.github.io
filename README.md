# Complex_

Aplicación web instalable de gestión escolar.

https://complexinteractive55-droid.github.io/

Android: Chrome, menú → Instalar app. iPhone: Safari, Compartir → Añadir a inicio. PC: Chrome o Edge, Instalar.

Conectada al nuevo Supabase. El acceso y las cuentas están habilitados; los módulos académicos conservan el esqueleto inicial. Los datos requieren conexión e inicio de sesión. No contiene claves de servicio.
